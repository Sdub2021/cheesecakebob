# Cheesecake Bob

Simple bakery website for Cheesecake Bob.

**Live preview (after enabling GitHub Pages):**  
https://sdub2021.github.io/cheesecakebob/

## Quick start
1. Go to the repo **Settings → Pages**
2. Source: Deploy from a branch → `main` → `/ (root)`
3. Save. Site will be live in about a minute.

## Customize
- Replace `[Your Phone Number]` and `[your@email.com]` in the Order section
- Update prices and flavors as needed
- Swap the emoji placeholders for real photos later
